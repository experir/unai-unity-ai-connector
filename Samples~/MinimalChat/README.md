# Minimal runtime chat

Import this sample from UNAI's Package Manager **Samples** section. Create a config using **Window > UnAI > Setup Wizard**, set a provider and model, then add `UnaiMinimalChat` to a GameObject and assign the config. Enter Play Mode to print a response to the Console.

Only the Runtime module is required. No Agent, Unity UI or TextMeshPro dependency is needed. Shared provider keys belong on a backend when shipping a game.
